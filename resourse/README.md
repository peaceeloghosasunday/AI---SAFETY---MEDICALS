# Annotated Resource Library

A curated list of resources for moving from beginner to intermediate in AI safety, medical AI, and evals. Each entry has a short description and my own verdict. I fill in the verdict after I have actually used the resource.

**Format of each entry:** what it is, who it is for, time needed, and my verdict.

---

## Phase 1: Foundations (Weeks 1-3)

### 1. GitHub: Hello World
- **Link:** https://docs.github.com/en/get-started/start-your-journey/hello-world
- **Type:** Free official tutorial
- **What it covers:** Creating a repository, committing changes to a file, and the basics of branches and pull requests, all in the browser.
- **Who it is for:** Complete beginners to GitHub. No coding or command line needed.
- **Time:** About 1 hour
- **Used in:** Week 1
- **My verdict:** _(fill in after completing)_

### 2. Kaggle Learn: Python
- **Link:** https://www.kaggle.com/learn
- **Type:** Free interactive micro-course (choose "Python")
- **What it covers:** Python basics: syntax, variables, functions, conditionals, lists, loops, strings, dictionaries. You write code in the browser with no installation.
- **Who it is for:** Beginners who learn best by doing short exercises.
- **Time:** About 6 to 10 hours
- **Used in:** Weeks 1-2
- **My verdict:** _(fill in after completing)_

### 3. CS50's Introduction to Programming with Python (CS50P)
- **Link:** https://cs50.harvard.edu/python
- **Type:** Free university course (Harvard), with video lectures and problem sets. The certificate is optional and paid.
- **What it covers:** Python from the ground up, plus testing and debugging.
- **Who it is for:** Beginners who want a deeper, more structured foundation than the micro-course.
- **Time:** Designed as a 10-week course at 3 to 9 hours a week, so it runs longer than the first two weeks of this plan. Take it as a deeper option alongside or after Kaggle Python.
- **Used in:** Weeks 1-2 and beyond
- **My verdict:** _(fill in after completing)_

### 4. Automate the Boring Stuff with Python
- **Link:** https://automatetheboringstuff.com
- **Type:** Free book, readable online (Al Sweigart)
- **What it covers:** Practical Python for total beginners, through everyday tasks like working with files, spreadsheets, and text.
- **Who it is for:** Beginners who want to see Python do something useful quickly. Good companion for Week 2's file and data work.
- **Time:** Read selected chapters; about 1 to 2 hours per chapter with practice
- **Used in:** Week 2
- **My verdict:** _(fill in after reading)_

### 5. Google: Machine Learning Crash Course
- **Link:** https://developers.google.com/machine-learning/crash-course
- **Type:** Free course with videos, interactive visuals, and exercises
- **What it covers:** Core machine learning ideas: how models are trained, loss, classification, evaluation metrics, working with data, and responsible AI.
- **Who it is for:** Beginners with some basic Python and school-level algebra.
- **Time:** About 15 hours in total. For Week 3, focus on the modules on training, classification, and evaluation metrics.
- **Used in:** Week 3
- **My verdict:** _(fill in after completing)_
